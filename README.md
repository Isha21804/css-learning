# CSS Learning 

## 📌 Introduction
This repository documents my journey of learning **Cascading Style Sheets (CSS)**.  
It includes practice files, examples, and mini projects focused on styling and responsive design.

## ✨ Key Highlights
- Fundamentals of CSS (selectors, colors, fonts)
- Layout techniques (Flexbox, Grid)
- Animations and transitions
- Responsive design practices

## 🛠️ Technologies Used
- HTML5 (for structure)
- CSS3 (for styling)
- Visual Studio Code
  
## 🎯 Purpose
- To build a strong foundation in CSS fundamentals  
- To practice modern layout techniques (Flexbox, Grid)  
- To explore animations and transitions for interactive design  
- To apply responsive design principles for different screen sizes  
- To create reusable styles for future projects  
- To document learning progress in a structured way
